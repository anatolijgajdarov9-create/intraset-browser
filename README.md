# 🌐 Intraset Browser

**Интранет-ориентированный браузер** с поддержкой локального AI-ассистента. Разработан для удобной работы в корпоративных сетях с возможностью выхода в Интернет.

---

## ✨ Возможности

- 🌐 **Браузер для интранет-сетей** — работа в локальных сетях с поддержкой Интернета
- 🤖 **Локальный AI-ассистент** — запускайте GGUF-модели (Llama, Qwen, Gemma и др.) прямо в браузере
- 📥 **Менеджер загрузок** — отслеживайте прогресс, открывайте папку с файлами
- 🔒 **Приватные вкладки** — изолированные сессии с отдельными cookies
- 📌 **Закладки, история, события** — всё для продуктивной работы
- ⚡ **Быстрая заметка** — записывайте мысли прямо на главной странице

---

## 🏗️ Архитектура

```
intraset-browser/
├── main.js                     ← Electron main process (окно, BrowserView, IPC, AI, загрузки)
├── preload.js                  ← contextBridge — мост между процессами
├── browser-preload.js          ← Preload для BrowserView (перехват уведомлений)
├── context-menu.html           ← Контекстное меню
├── src/
│   ├── App.jsx               ← Корневой компонент
│   ├── index.css             ← Стили, анимации, CSS-переменные
│   └── components/
│       ├── HomePage.jsx      ← Главная страница (дашборд)
│       ├── AiChatPage.jsx    ← AI-чат
│       ├── BlockedPage.jsx   ← Страница блокировки
│       └── BookmarksBar.jsx  ← Панель закладок
├── llama server/              ← Llama.cpp бинарники
└── docs/                     ← Документация
```

### Технологии

| Слой | Технология |
|------|-----------|
| Оболочка | Electron 27 |
| UI | React 18 + Vite 5 |
| AI | llama-server (llama.cpp) |

## 🤖 AI-ассистент

### Загрузка модели

1. Скачайте GGUF-модель (Llama, Qwen, Gemma, Mistral и др.)
2. Нажмите **"Выбрать модель (.gguf)"** на главной странице или в боковой панели
3. Укажите путь к `llama-server.exe` (в комплекте `llama server/`)
4. Выберите размер контекста (по умолчанию 4096 токенов)

### Возможности

- 📖 **Анализ страниц** — выделите текст и попросите AI объяснить или суммировать
- 💬 **AI-чат** — общайтесь с моделью в отдельной вкладке
- 🔍 **Веб-поиск** — AI может искать информацию в интернете
- 🧠 **Режим "подумать"** — модель выводит мысли перед ответом

## 🔧 Конфигурация

### Интранет-домены

Отредактируйте `src/config/intranet.js`:

```js
const intranetDomains = ['.local', '.intra', '.corporate'];
const intranetUrls = ['http://localhost:3000'];
```

### Поисковая система

```js
defaultSearch: 'https://yandex.ru/search/?text='
```
